
# Evaluating and Improving the Quality of LLM-Generated Code

This repository contains the presentation slides and hands-on notebooks from our **FSE 2026 tutorial, "Evaluating and Improving the Quality of LLM-Generated Code,"** shared as resources for our CASCON tutorial.

## Repository Contents

- **Tutorial Slides:** Presentation materials covering the evaluation and improvement of LLM-generated code.
- **Code Quality & Security Notebook:** Hands-on evaluation of LLM-generated versus human-written code using SonarQube and Bandit.
- **Intersectional Bias Notebook:** Exercises for measuring and reducing technology preferences and intersectional biases in AI models.
- **Agentic Bug Localization Notebook:** Exercises exploring bug report reformulation, information retrieval, and agentic bug localization.
- **Explainability Notebook:** Walkthrough of vulnerability analysis and different explanation methods for LLM-generated code repairs.

## Getting Started

The notebooks can be opened in **Google Colab** to follow along with the hands-on exercises or explore the methods independently. The tutorial slides provide additional background, examples, and references for each topic.

These materials are intended to support further learning and experimentation with LLM-generated code quality, security, fairness, and explainability.
